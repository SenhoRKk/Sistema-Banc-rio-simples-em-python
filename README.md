🏦 Sistema Bancário Simples em Python

📌 Sobre o projeto

Este projeto consiste em um sistema bancário simples desenvolvido em Python, com o objetivo de praticar conceitos fundamentais da programação, como funções, estruturas condicionais, laços de repetição e manipulação de variáveis.

⚙️ Funcionalidades

- Adicionar receitas.
- Adicionar despesas.
- Consultar saldo atual.
- Consultar total de receitas.
- Consultar total de despesas.
- Mostrar histórico de movimentações.
- Impedir valores negativos.
- Impedir despesas maiores que o saldo disponível.

💻 Tecnologias utilizadas

- Python 3

▶️ Como executar

1. Baixe ou clone este repositório.
2. Abra o arquivo do projeto no seu ambiente Python.
3. Execute o programa.
4. Utilize o menu apresentado no terminal para escolher as operações.

📚 Objetivo

Este projeto foi desenvolvido com fins educacionais, como parte da minha jornada de aprendizado em Python, colocando em prática os conceitos estudados por meio de um projeto funcional.
